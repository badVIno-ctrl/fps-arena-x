## Главный вывод: ищите «мёртвые» поля статов

`game/arsenal/attachments.js` считает полный свод характеристик сборки, но
исторически **почти никто за пределами `arsenal/` его не читал**. За сессии
найдено и починено **пять** таких полей:

| поле | что было сломано | коммит |
|---|---|---|
| `loudness` | ИИ слышал выстрел на фиксированных 90 м — глушитель был косметикой | `fbdeeea`, `b4e1e4f` |
| `suppressed` | звук брал глушитель из определения оружия, а не навинченный | `786fb8a` |
| `zoom` | 4x ПСО давал то же поле зрения, что открытый прицел | `470d35b` |
| `sightAxis` | `rig.sightAxis()` не вызывался никем — глаз смотрел под оптику | `e131f25` |
| `weight` | вес считался по голому оружию, обвес ничего не весил | `df8d428`, `58a51bf` |

**Проверьте так же:** `sway`, `recoilYaw`, `spreadHip`, `adsTime`, `ergonomics`.

Аудит стоит две команды и не требует запуска браузера:

```bash
# 1. все поля, которые считает resolveStats
grep -oE "^\s+[a-zA-Z]+:" game/arsenal/attachments.js | tr -d ' :' | sort -u

# 2. для каждого поля — кто его читает вне arsenal/
grep -rn "\.ИМЯ_ПОЛЯ\b" game/ --include=*.js | grep -v "game/arsenal/"
# пусто => поле мёртвое, это баг
```

### Как подключать поле к движку
Движок **не должен** импортировать `arsenal`. Установленный паттерн — инъекция
аксессора в `game/arsenal/index.js` (~строка 108), рядом с существующими:

```js
wp.resolvedStats = () => this.activeRig()?.stats() ?? null;
wp.sightPoint    = () => this.activeRig()?.sightAxis() ?? null;
```

Потребитель берёт его через реестр и **обязательно** имеет фолбэк:

```js
const stats = this.ctx.peek('weapons')?.resolvedStats?.();
const value = stats?.поле ?? СТАРОЕ_ЗНАЧЕНИЕ;  // работает без arsenal
```

Не забудьте `delete this.weapons.ВАШ_АКСЕССОР;` в teardown (~строка 182).

`rig.stats()` мемоизирован на счётчике `_rev` — читать можно каждый кадр.
**Если добавляете новый слот или переключатель — увеличьте `_rev` рядом с
мутацией**, иначе кэш отдаст устаревшие числа.

## Грабли, на которые я наступил

- **Автокоммит дважды откатывал правки уже после коммита.** Не доверяйте выводу
  `git commit` — сверяйте дерево с HEAD:
  ```bash
  git show HEAD:путь/файл | grep -c "маркер"; grep -c "маркер" путь/файл
  ```
  Из-за этого история разбита на больше коммитов, чем нужно по смыслу.

- **Тяжёлый `eval` в браузере отваливается по таймауту CDP.** `rig.swap()`
  пересобирает модели, поэтому цикл по пяти прицелам в одном `eval` не
  укладывается. Дробите на мелкие вызовы — по одному замеру за раз.

- **Проверяйте пробу, прежде чем «чинить» код.** Дважды замер показывал нули и
  выглядел как провал: один раз страница держала устаревший бандл (нужна
  перезагрузка), другой раз ветка ADS смотрела на собственный `adsT` вьюмодели, а
  не на `movement.adsAmount`, который я задавал.

- Прицеливание правой кнопкой в headless-браузере не работает — pointer lock не
  захватывается. Задавайте состояние напрямую и тикайте систему вручную.
